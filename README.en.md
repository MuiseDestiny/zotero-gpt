Awesome GPT is an AI reading and writing assistant for Zotero. Ask questions, summarize, translate, and organize content using full papers, selected text, and notes.

## Documentation

See the [documentation](https://plugins.muisedestiny.xyz/docs/gpt) for usage. **Pro features** require [purchase](https://plugins.muisedestiny.xyz/) and [activation](https://plugins.muisedestiny.xyz/guide).

## Installation & updates

1. [Download the plugin](https://gitee.com/MuiseDestiny/plugins/raw/master/zotero-gpt.xpi) and save the `.xpi` file.
2. In Zotero, open Tools → Plugins, click the gear icon in the upper-right corner, and choose Install Plugin From File. Select the downloaded file.

After installation, **check for updates** in the upper-right corner of Zotero Settings → GPT Pro.
