Awesome GPT 是一款面向 Zotero 的 AI 阅读与写作辅助插件，支持结合文献全文、选中文本和笔记进行问答、总结、翻译与内容整理。

## [使用文档](https://plugins.muisedestiny.xyz/docs/gpt)

使用方法见文档，其中 **Pro 功能**需[购买](https://plugins.muisedestiny.xyz/)并[激活](https://plugins.muisedestiny.xyz/guide)。

## 安装与更新

1. [下载插件](https://gitee.com/MuiseDestiny/plugins/raw/master/zotero-gpt.xpi)，保存 `.xpi` 文件。
2. 打开 Zotero「工具 → 插件」，点击右上角齿轮，选择「从文件安装插件」，选中下载的文件。

安装后，在 Zotero「设置 → GPT Pro」右上角可**检查更新**。
